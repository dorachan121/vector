## 3. 配当（RTP）の検証結果

**実行環境：.NET SDK 8.0.132 ／ 実行日：2026-10-22 ／ `Tools/Simulator`（CI と同じコマンド）**

「厳密」は全列挙・動的計画法・確率の解析で求めた値、「シミュレーション」はモンテカルロ法による確認です。

| ゲーム | 検証の方法 | 結果 | 設計値（README） |
|---|---|---|---|
| VECTOR BONUS | 6 デッキの 5 枚の組み合わせ（約 2.4×10¹⁰ 通り）を全列挙 | **RTP 95.654%** | 95.65% |
| CROWN DICE ANTE | 252 通りの手 × 462 通りの残し方を後ろ向きに解く | **RTP 96.8522%**（王冠の目ごとに 96.84〜96.85%） | 96.852% |
| CROWN DICE OPENING | 厳密 | **RTP 94.920%** | 94.920% |
| COLOSSEUM | 全状態の勝率を動的計画法で解く | **勝率 48.3561% / RTP 96.7123%** | 96.712% |
| FOUR BEASTS DERBY | 着順の確率を厳密計算し、全出走表で平均 | **単勝 95.702% / 馬単 96.601%**（最大 97.00%） | 95.7% / 96.6% |
| DELVE | 深さごとの生存確率から厳密計算 | **どこで引き返しても 96.750〜97.000%**（B10 で x2,234.88） | 96.75〜97.00% |
| ORBIT | 全スピンを数え上げ | **すべての賭け先で 97.2973%** | 97.297% |
| HARPOON | 捕獲率 = 97 ÷ 倍率（整数の比） | **すべての獲物で 97.0000%** | 97.000% |
| SUGOROKU | 全状態を後ろ向きに解く | **最善手 96.4932%**（大きい目だけ 41.14%、目先の小判だけ 83.47%） | 96.493% |
| HANABI | すべての乱数を数え上げ | **どの倍率で開いても 97.000% 以下** | 97.000% |

シミュレーションによる確認（抜粋）：CROWN DICE（戦略ヒント 20,000 回）97.045% ±1.581%、COLOSSEUM（20,000 戦）96.760% ±1.385%、SUGOROKU（最善手 100,000 回）96.446% ±1.039% と、いずれも厳密値と 95% 信頼区間の範囲で一致しました。VECTOR のメインベットは「1 手先だけを見る打ち方」で RTP 66.85% となり、**腕で RTP が変わるスキルゲーム**であることも確認できます（戦略ヒントどおりで 96.8%）。

## 4. 静的解析

`.editorconfig` で「不要な using」「使われない private メンバー」「読まれないフィールド」「使われない引数」を警告にし、Tools のビルドでは**警告をエラー扱い**にしています。上記の `dotnet test` ／ `dotnet build Tools/Simulator` は警告なしで成功しました。
